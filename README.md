# FriendSMP — Official Repository

Welcome to the official repository and documentation hub for FriendSMP, a private, whitelisted community-driven Minecraft Survival Multiplayer server. 

---

## About FriendSMP

FriendSMP is built for players who want a genuine, long-term survival experience without the chaos of public servers. We focus on building amazing projects, collaborating on large-scale farms, and fostering a chill, friendly community. 

---

## Server Specifications & Compatibility

> Important Notice: FriendSMP runs exclusively on Java Edition for PC. Bedrock Edition, Pocket Edition (PE), and console versions are not eligible or supported. Make sure you are using an official Java PC client to connect.

* Minecraft Version: Latest Stable Release (Java Edition)
* Platform: PC Only (Windows, macOS, Linux)
* Account Type: Both Premium (Official) and Cracked accounts are supported
* Server Type: Whitelisted Survival Multiplayer (SMP)

---

## Core Rules & Guidelines

To keep the community safe, fun, and active for everyone, all members must adhere to the following guidelines:

1. Keep it Fair: No cheating, hacking, X-ray, or exploit abusing of any kind.
2. Respect Players: Zero tolerance for griefing, stealing, harassment, or toxicity.
3. Build Responsibly: Respect other players' claimed land and give reasonable spacing for mega-bases.
4. Be Active: Members who remain inactive for extended periods without notice may be un-whitelisted to keep slots open.
5. No AI Applications: Submitting fake or AI-generated text in your whitelist application will result in an immediate blacklist.

---

## Whitelist & Application Process

Because FriendSMP is a private, whitelisted community, every new member must go through a quick screening process:

1. Head over to our Discord server: **[Click Here to Join](https://dsc.gg/friendsmpp)**
2. Navigate to the applications channel.
3. Click the application button to start your form.
4. Answer all questions honestly and in your own words.
5. Wait for the staff team to review your application. Once accepted, you will receive the whitelist role and server IP!

---

## Staff & Community Hierarchy

Our server structure ensures smooth management and fair gameplay:

* Owner / Developer: Oversees backend setup, plugins, and server maintenance.
* Administrators / Senior Moderators: Handles major player reports, staff management, and appeals.
* Junior Moderators: Monitors daily chat and assists new members.
* Senior Members / Builders / Content Creators: Active community contributors and creators.
